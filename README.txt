Zaki Bashir Student Portfolio Website

Files:
- index.html
- styles.css
- script.js
- assets/ (portfolio images)

Preview locally:
Double-click index.html, or run a simple local server in this folder.

Deploy to GitHub Pages:
1. Create a GitHub repository.
2. Upload all files/folders from this directory to the repository root.
3. In GitHub repository Settings > Pages, choose the main branch as the publishing source.
4. Optionally connect a custom domain in GitHub Pages settings.

Privacy note:
This public-facing version intentionally avoids publishing the student's current school name, current local facility, exact contact information, or home location. Review all photos and text with the student/parent before publishing.
